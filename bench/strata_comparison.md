# Сравнение со Strata, llama.cpp и нашим движком (2026-11-08)

Все цифры — генерация, ток/с. «Короткий» — среднее по 8 коротким промптам (26–64 токена), «длинный» — промпт на 17 160 токенов. На каждый запрос — 256 токенов, жадный выбор, EOS игнорируется, 2 прохода. Промпты одинаковые у всех трёх движков (`bench/prompts/<модель>.json`).

**Машина.** RTX 4070 SUPER 12 ГБ (драйвер 621.01, WDDM, монитор на этой же карте), i7-13700KF, 64 ГБ DDR5, Windows 11, схема питания «Высокая производительность», фоновые программы закрыты.

**Версии:**
- Strata — приложение 0.2.12, движок 0.1.58 (`windows-x86_64-cuda-cuda13`), рекомендуемые настройки `strata launch`, `--tune skip`;
- llama.cpp — коммит 80d2c0c2c (официальная сборка b12189);
- наш движок — тот же коммит + патчи `engine/patches/0001–0009`, настройки из `aic build`.

## Qwen3.8-Flash-Next

**Файл** (один и тот же у всех): `models/qwen38/Qwen3.8-Flash-Next-GSQ-RCO-Q2_0-0000{1,2}-of-00002.gguf`. SHA256 сверены с HF, см. `bench/logs/qwen38_sha256.txt`.

| | Короткий, круг 1 / 2 | Длинный, круг 1 / 2 | Промпт 17K | Драфт | Принято (короткие / длинный) |
|---|---|---|---|---|---|
| Strata | 85.4 / 86.2 | 95.2 / 91.6 | 2208 / 2387 | свой MTP-слой (докачан, 5.2 ГБ; в VRAM 840 МиБ), окно до 4, `--spec-min-p 0.5` | 66–68% / 68–70% |
| llama.cpp | 48.9 / 49.0 | 50.3 / 50.4 | 237 / 244 | unsloth `mtp-Qwen3.8-Flash-Next-Q4_K_M.gguf`, длина 3, эксперты головы в RAM (`-cmoed`), кэш 5500 | 68% / 81–83% |
| наш движок | 46.8 / 46.7 | 49.9 / 48.9 | 404 / 404 | та же голова, длина 2, голова в VRAM, кэш 3180, 8 CPU-потоков | 76% / 92% |
| llama.cpp без драфта | 40.3 / 40.3 | 38.8 / 40.0 | 328 / 329 | — | — |

Без драфта наш движок даёт 47.4 ток/с (проба `aic build`), то есть на 18% быстрее llama.cpp без драфта.

**Важно: Strata считает приближённо.** По умолчанию на CUDA у неё включён `STRATA_ROUTE_TAIL_SKIP=7`. Промахнувшийся эксперт, которого все токены окна выбрали на 7-м месте или ниже (из 10), не считается вовсе. Авторы пишут, что ответы немного меняются (KLD 0.003–0.006 в их замерах). В нашем прогоне таких пропусков было 374 274 (`bench/logs/strata/q2_0-32k.engine.log`, «route tail skip»). llama.cpp и наш движок считают всех экспертов. Честное сравнение — повтор с `--tail-skip 0`; он ещё не сделан (HANDOFF.md).

Что ещё видно в журнале Strata:
- VRAM-кэш 3812 экспертов (4.9 ГиБ), заполнен заранее из профиля (`expert-profile.bin`), попаданий 63–79%;
- 4–7% промахов GPU читает сам по PCIe (`PCIe share 0.20`, канал 24.2 ГБ/с);
- 15 CPU-потоков, включая E-ядра;
- предупреждения о нехватке VRAM: свободно 314–641 МиБ.

## Qwen3.6-35B-A3B

**Файл** (один и тот же у всех): `models/qwen36mtp/Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf` из `unsloth/Qwen3.6-35B-A3B-MTP-GGUF`, MTP-слой внутри. Файл без MTP Strata не запускает.

| | Короткий, круг 1 / 2 | Длинный, круг 1 / 2 | Промпт 17K | Драфт | Принято (короткие / длинный) |
|---|---|---|---|---|---|
| Strata | 37.1 / 37.2 (повтор с `--parallel 1`: 37.7) | 30.5 / 30.9 (31.0) | 2065 / 2073 (2178) | MTP загружен, но **0 драфтов** | — |
| llama.cpp | 91.8 / 92.5 | 98.9 / 98.1 | 607 / 612 | встроенный MTP, длина 3, кэш 7500 | 68% / 83% |
| наш движок | 90.8 / 91.1 | 97.7 / 94.8 | 774 / 772 | встроенный MTP, длина 2, кэш 7175, 6 потоков | 77% / 89% |

Журнал Strata (`bench/logs/strata/ud-q4_k_xl-32k.engine.log`):
- в VRAM 6–7 экспертов из 256 на слой (0.5 ГиБ);
- остальное считает CPU на 16 потоках;
- «drafts accepted 0 of 0» во всех запросах.

Её путь для Qwen3.6 (`strata-q36`) явно второстепенный.

На этом файле наш движок идёт вровень с llama.cpp, а с отдельным файлом MTP-головы (веха 1, UD-Q4_K_M) — на 15–29% быстрее. Возможные причины — в DECISIONS.md, D10.

## Как повторить

```
python bench/strata_compare.py qwen38 --rounds 2                # все три движка
python bench/strata_compare.py qwen38 --rounds 2 --tail-skip 0  # Strata без пропуска экспертов
python bench/strata_compare.py qwen36 --rounds 2
```

Команды по отдельности, сырые логи и журналы движков — в BENCHMARKS.md, раздел «Сравнение со Strata: сводка, команды, логи».
